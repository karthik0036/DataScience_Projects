## Project Overview

- Developed Recurrent Neural Network (RNN) models using LSTM (Long Short-Term Memory) and GRU (Gated Recurrent Unit) architectures for sequential data prediction.

- Implemented a complete deep learning pipeline, including:

- Data Cleaning and Preprocessing

- Feature Scaling

- Sequence Generation for Time-Series

- Train-Test Split

- Built and trained both LSTM and GRU models using TensorFlow/Keras.

- Applied Dropout Regularization to prevent overfitting and improve generalization.

- Evaluated model performance using:

- Training vs Validation Loss Comparison

- Prediction vs Actual Visualization

- Comparative Analysis between LSTM and GRU

- Structured the project for modular implementation and reproducibility.
